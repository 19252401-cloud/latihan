# Video Looper 🔁

Aplikasi website untuk loop video pendek (8 detik) menjadi video berdurasi 30 menit.

## Fitur

- Upload video pendek (8 detik atau durasi lainnya)
- Atur durasi target (default 30 menit, maksimal 60 menit)
- Preview video sebelum proses looping
- Tampilan progress bar dan informasi loop secara real-time
- Download hasil video yang sudah di-loop
- Desain responsif untuk desktop dan mobile

## Cara Penggunaan

1. Buka `index.html` di browser
2. Klik **Pilih Video** untuk memilih file video pendek
3. Atur durasi target (default: 30 menit)
4. Klik **Mulai Loop & Rekam** untuk memulai proses
5. Tunggu hingga proses selesai atau klik **Berhenti** untuk menghentikan
6. Download video hasil looping

## Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)
- MediaRecorder API
- Canvas API

## Persyaratan

- Browser modern (Chrome, Firefox, Edge) yang mendukung MediaRecorder API
- Tidak memerlukan server - berjalan sepenuhnya di sisi klien
